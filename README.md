# Common All Website

A modern, responsive website template that works across all devices and platforms. This project provides a clean and professional starting point for any website project.

## Features

- 🎨 **Modern Design**: Clean and contemporary user interface
- 📱 **Fully Responsive**: Works perfectly on desktop, tablet, and mobile devices
- 🚀 **Fast & Lightweight**: Optimized for performance with vanilla JavaScript
- ♿ **Accessible**: Built with accessibility best practices
- 🎯 **Easy to Customize**: Simple structure for quick modifications
- 🔧 **No Build Tools Required**: Pure HTML, CSS, and JavaScript

## Project Structure

```
Common_All_Website/

├── script.js           # JavaScript functionality
```

## Sections

The website includes the following sections:

1. **Navigation Bar**: Fixed navigation with smooth scrolling and mobile menu
2. **Hero Section**: Eye-catching landing section with call-to-action
3. **About Section**: Information about the website/company with feature highlights
4. **Services Section**: Grid layout showcasing services/offerings
5. **Contact Section**: Contact form and information
6. **Footer**: Copyright and social links

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A text editor (VS Code, Sublime Text, etc.)
- Optional: A local web server for development

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Radhe70233984/Common_All_Website.git
```

2. Navigate to the project directory:
```bash
cd Common_All_Website
```

3. Open `index.html` in your web browser or use a local development server.

### Using a Local Server (Recommended)

#### Option 1: Python
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

#### Option 2: Node.js (http-server)
```bash
npx http-server -p 8000
```

#### Option 3: VS Code Live Server Extension
Install the "Live Server" extension in VS Code and click "Go Live" in the bottom right.

Then open your browser and navigate to `http://localhost:8000`

## Customization

### Colors

Edit the CSS variables in `styles.css` to change the color scheme:

```css
:root {
    --primary-color: #3498db;      /* Main brand color */
    --secondary-color: #2c3e50;    /* Secondary color */
    --text-color: #333;            /* Text color */
    --light-bg: #f8f9fa;           /* Light background */
}
```

### Content

- Edit `index.html` to change text content, sections, and structure
- Update section titles, descriptions, and contact information
- Add or remove sections as needed

### Styling

- Modify `styles.css` to adjust layouts, spacing, and visual design
- All styles are well-organized and commented
- Responsive breakpoints are defined for mobile and tablet devices

### Functionality

- Update `script.js` to add or modify interactive features
- Current features include:
  - Mobile menu toggle
  - Smooth scrolling
  - Form handling
  - Scroll animations
  - Scroll-to-top button
